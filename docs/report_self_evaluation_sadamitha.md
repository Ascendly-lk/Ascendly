# Self-Evaluation -- Sadamitha Liyanage

Throughout the development of the Ascendly platform, my primary contributions centred on quality assurance, AI agent evaluation, and observability infrastructure. I designed and implemented a multi-layered test suite for the backend, comprising deterministic pytest tests for the Data Analyst pipeline's output schema, walk-forward MAPE accuracy tests for the SARIMAX and SES forecasting tools, and LLM-judge quality tests using the DeepEval framework to assess strategist faithfulness and chat-agent answer relevancy against defined thresholds. To support continuous integration, I authored two GitHub Actions workflows: a deterministic test pipeline that runs on every push without requiring LLM credentials, and a manually triggered LLM-judge pipeline that evaluates agent output quality against Azure GPT-4o. I also built the Arize Phoenix observability layer, instrumenting both CrewAI and LiteLLM pipelines with OpenTelemetry spans and creating a dedicated ADK span wrapper for Google ADK benchmark agent tracing. This work gave me substantial practical experience in statistical forecast validation, LLM evaluation methodologies, CI/CD pipeline design, and distributed tracing with OpenTelemetry. More broadly, it deepened my understanding of how rigorous testing and observability practices are essential to maintaining reliability in AI-driven systems where outputs are inherently non-deterministic.
